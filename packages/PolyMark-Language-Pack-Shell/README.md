# PolyMark-Language-Pack-Shell

Standalone companion package for [PolyMark](https://thepolymodframework.carrd.co/).
Adds language-specific highlighting to PolyMark fenced code blocks tagged
`bash`, `sh`, `shell`, `zsh` or `console` by embedding Sublime Text's built-in
`source.shell` highlighting.

```bash
echo "hello world"
ls -la
```

## Install

Copy the `PolyMark-Language-Pack-Shell` folder into your `Packages` directory
next to `PolyMark`, then restart Sublime Text. No PolyMark edits are needed —
PolyMark detects this package automatically.
