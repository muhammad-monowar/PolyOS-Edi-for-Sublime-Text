# ProseMode

A minimal, low-contrast color scheme for focused writing in Sublime Text.

## Install (standalone)

Drop this `ProseMode` folder into your Sublime Text packages directory:

- Windows: `%APPDATA%\Sublime Text\Packages\`
- macOS: `~/Library/Application Support/Sublime Text/Packages/`

Access it via `Preferences > Browse Packages...`.

## Activate

- Manually: `UI: Select Color Scheme > ProseMode`.
- With the prose profile: the `Distraction Free` and `Plain Text` settings in
  `Packages/User` reference this scheme automatically.
